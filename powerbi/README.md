# Power BI Assets

This folder contains files used to build the Power BI dashboard.

## Files

- `EHR_Readmission_Quality_Analytics.pbip`: current Power BI Project file to open.
- `EHR_Readmission_Quality_Analytics.Report/`: report with three completed dashboard pages.
- `EHR_Readmission_Quality_Analytics.SemanticModel/`: embedded semantic model, tables, and grouped DAX measures.
- `measures.dax`: recommended DAX measures.
- `theme-ehr-readmission.json`: report theme for consistent colors, typography, and visual styling.

## Open

Open this file in Power BI Desktop:

`EHR_Readmission_Quality_Analytics.pbip`

If a `.pbix` export is needed, use **File > Save as** in Power BI Desktop and save a copy as `EHR_Readmission_Quality_Analytics.pbix`.
